# wtj

The official Website of **Where's The Juice**

## System Requirements

Minimum Node.js Verson 20.9

## How to run locally

1. clone repo into local repository for example using https:

- `git clone https://github.com/littilemike11/wtj.git`

2. go into frontend folder

- `cd /wtj/frontend`

3. install node modules

- `npm install`

4. start local development with live updates

- `npm run dev`
